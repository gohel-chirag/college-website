# College Website

A simple multi-page college website created using **HTML5** as part of my web development practice.

The website provides basic information about the college, courses, faculty, facilities, timetable, admission and contact details.

## Pages

* Home
* About
* Courses
* Faculty
* Facilities
* Timetable
* Admission
* Contact

## What I Practiced

* HTML page structure
* Navigation and links
* Tables and forms
* Images
* Semantic HTML
* Connecting multiple HTML pages

## Technology Used

* HTML5

This project helped me practice HTML by building a complete multi-page website instead of working only with small examples.
